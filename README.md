# san3pedia — Portofolio Pengembang Web

Portofolio pribadi yang berisi layanan pembuatan aplikasi web, contoh proyek, alur kerja, dan informasi kontak.

## Layanan
- Website company profile
- Aplikasi web custom
- Dashboard dan admin panel
- Integrasi dan API

## Teknologi
HTML, CSS, JavaScript (tanpa framework, sehingga ringan dan mudah di-hosting).

## Cara Menjalankan
Buka `index.html` langsung di browser, atau akses melalui GitHub Pages di:
https://san3pedia.github.io

## Kontak
Hubungi melalui GitHub: https://github.com/san3pedia
